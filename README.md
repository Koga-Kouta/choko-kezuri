# チョコけずり

スティック菓子のチョコを爪で削り落とすタイムアタック。ビスケットまで削りすぎると折れる。

- `index.html` 1ファイルだけで動く静的サイトです（ビルド不要）。
- Vercel では Framework Preset を **Other**、Build Command と Output Directory は空のままでデプロイできます。
- 結果画面の「Xで結果をポスト」は、公開先のURLと `#ポッキーの日` `#チョコけずり` を付けて投稿画面を開きます。
- 開発用: URL の末尾に `#pretz` を付けると、5% のハズレ（チョコなしスティック）を必ず出せます。
